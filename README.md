# Bible Nexus

English Christian content website published at `https://hermano-padawan.github.io/bible-nexus/` through GitHub Pages. Local builds remain compatible with the future custom domain `https://biblenexus.site`.

Run `npm install` and `npm run dev` locally. Run `npm run build` for production.

To publish an article, add a Markdown file to `src/content/articles`. The schema, routing, category listings, metadata, and related links are automatic.
